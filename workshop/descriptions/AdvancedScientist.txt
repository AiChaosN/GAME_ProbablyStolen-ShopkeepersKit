[h1]【玩法】掌柜帮手·高级科学家[/h1]
[b]新职业，改变游戏机制。[/b] 界面中英双语，跟随游戏语言。开发中。

[h2]职业[/h2]
职业选择界面第 2 页的“高级科学家”，精通模组工艺。开局：机器区、空白模组制造机、词条镶嵌机（各附电池）、三块随机模组。
[list]
[*][b]职业能力[/b]：直接放在机器区里的机器每天按两天运转（多耗一次电；冰箱、发电类等不加倍；设置里可关）。
[*][b]空白模组制造机[/b]：每晚耗电，把电子元件、金属、线缆做成低 / 中 / 高级空白模组（可镶 1 / 2 / 3 个词条）。
[*][b]词条提取机[/b]（找杰克逊博士买）：把模组的数值做成基础芯片、特殊词条做成特殊词条芯片，模组变回空白模组。
[*][b]词条镶嵌机[/b]：把芯片镶到空白模组上，数值相加，特殊词条最多 2 个。
[*]之后加入：词条合成机。
[/list]

[h2]安装[/h2]
订阅后：主菜单 → 改装件 → 选中本 mod → 审阅并启用 → 重启游戏，新游戏时选这个职业。不需要任何特殊权限。

[h1][Gameplay] Shopkeeper's Kit: Advanced Scientist[/h1]
[b]A new profession that changes game mechanics.[/b] UI in Chinese and English, following the game language. In development.

[h2]Profession[/h2]
"Advanced Scientist" on page 2 of the profession screen, a module-crafting expert. Starts with a Machine Bay, the Blank Module Maker and the Affix Inlayer (each with a battery) and three random modules.
[list]
[*][b]Ability[/b]: machines placed directly in a Machine Bay run two days' worth every day (using power again; fridges, generators etc. excluded; can be turned off).
[*][b]Blank Module Maker[/b]: each night it uses power to turn electronic parts, metal and wire into low / mid / high grade blank modules (1 / 2 / 3 slots).
[*][b]Affix Extractor[/b] (sold by Dr. Jackson): turns a module's stats into a base chip and its affixes into affix chips; the module becomes a blank.
[*][b]Affix Inlayer[/b]: puts chips into blank modules; stats add up, at most 2 special affixes.
[*]Coming next: a chip merger.
[/list]

[h2]Install[/h2]
After subscribing: main menu → Mods → select this mod → Review and enable → restart, then pick the profession in a new game. No special capabilities required.
