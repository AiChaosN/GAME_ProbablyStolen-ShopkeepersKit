## 做什么

原版的**高级滤水器**耐久度 400，每天开始时恢复 50 点。本 mod 让它可以“充能”：

- 把一个**滤水器**（普通滤水器、另一个高级滤水器、水培芦苇滤芯）拖到高级滤水器上，松手：它剩下的耐久度**全部转给**高级滤水器，原来那个就用完了；
- 高级滤水器的耐久度上限提高到**普通滤水器的 20 倍 = 8000**（设置里可改成 5 / 10 / 40 倍）；
- 快满时只转需要的部分，剩下的留在原来那个滤水器里，不浪费；
- 不用打开水罐：直接拖到**装着高级滤水器的水罐**上也行（窗口第一层有滤芯槽的其他设备也一样）；
- 悬停时显示绿色的“对 高级滤水器 使用 滤水器”，松手后提示“高级滤水器耐久度 +400 → 1200/8000”。

用完的滤水器留在原地（耐久度 0，原版里用完的滤水器也是这样），不想要可以扔进垃圾桶。

### 对平衡的影响

- 一个高级滤水器能装下 20 个普通滤水器的量，换滤水器的次数大大减少；
- 高级滤水器每天恢复 50 点的效果照旧，而且能一直恢复到新上限（原版到 400 就停）；
- 售价：充满时与原版满耐久的高级滤水器同价；没充满按比例打折（例如 4000/8000 约为满价的 75%）。原版的估价公式里有一项“上限 ÷ 默认上限”，本 mod 把两者一起提高，避免充能后售价翻十倍。

### 不会改变的

- 只对你自己的东西生效，一次一个；多选一起拖时不充；
- 韧棉织物虽然也能当滤芯用，但它是做衣服的材料，不拿来充，免得误拖掉；紫外线灯没有耐久度，也不参与；
- 没充过能的高级滤水器和原版完全一样。

## 和「便利替换」一起用

两个 mod 可以同时装。水罐里装着**高级滤水器**时，拖滤水器上去是**充能**（满了就提示已满，不会把它换下来）；装着普通滤水器时，拖滤水器上去才是**换件**。

## 安装

1. 构建（见[仓库首页](../../README.zh-CN.md)“从源码构建”）后，把 `dist/FilterRecharge/` 整个文件夹复制到游戏目录的 `Mods` 文件夹里：
   ```
   <游戏目录>/Mods/FilterRecharge/manifest.xml
   <游戏目录>/Mods/FilterRecharge/FilterRecharge.dll
   ```
   游戏开着的时候 DLL 被锁住，替换前先退出游戏。
2. 启动游戏 → 主菜单 **改装件** → 选中 **【玩法】掌柜帮手·滤水器充能** → **审阅并启用** → 按提示重启游戏。
3. 本 mod **不申请任何特殊权限**；用游戏自带的扫描器检查（[`tools/ScanCheck`](../../tools/ScanCheck)）结果是无权限、无拦截、无发现。

卸载：已经充过能的高级滤水器保持当时的耐久度和上限（存在存档里的是物品自己的数值），之后照原版用。

## 设置

改装件界面选中本 mod → **设置**；或编辑 `%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\ModConfigs\chaos5090.filter-recharge.json`。

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 滤水器拖到高级滤水器上充能；关掉 = 原版 |
| `capMultiplier` | `20` | 高级滤水器耐久度上限 = 400 × 这个倍数（5 / 10 / 20 / 40）。已经充到更高上限的不会被降回去 |

## 怎么测试

> 测试前先备份存档：`%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\` 下的 `save_*.es3`。

1. 准备一个高级滤水器（解锁卖水的人脉后，杰克逊博士店里偶尔有卖）和几个普通滤水器。
2. 把普通滤水器拖到高级滤水器上：悬停时显示绿色，松手后提示耐久度增加；鼠标指着高级滤水器看耐久度，应为“耐久度：800/8000”之类。
3. 被拖的那个滤水器耐久度变成 0。
4. 把高级滤水器放进水罐，再把普通滤水器拖到水罐上：同样充能。
5. 充满后再拖：提示“已经满了”，什么都不变。
6. 游戏日志 `Player.log` 里搜 `[FilterRecharge]`：每次充能有一行“充能：……”。

## 实现

| 文件 | 内容 |
|---|---|
| `src/Recharge.cs` | 判断与充能。补丁：`GameItem.MayTarget` / `CanTarget` 后置（把“滤水器 → 高级滤水器”算作可以使用），`GameItem.Target` 前置（充能并跳过原版，优先级高于便利替换），`GameSlotInventory.MayHaveValidInventorySlot` 后置（只在鼠标正拖着这件物品时，把装着高级滤水器的槽报告为放不进，让拖到水罐上悬停时显示绿色）。耐久度用游戏的 `DurabilityHelper.SetDurability`（当前 / 上限 / 默认三个值） |
| `src/FilterRechargeMod.cs` | 入口、配置 |
